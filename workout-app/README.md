# Lift Log

A phone workout app for beginners: follow a plan, log every set, watch animated how-tos, and learn the basics of training and food.

- **Accounts:** email and password sign-up and log in, password reset, and each person's data synced to their own private row in Supabase. Without `config.js` filled in, it runs on the device with no login. Setup: [SETUP.md](SETUP.md).
- **Plans:** four ready-made plans (Glute plan, Beginner full body, Home workout, Upper body), or build your own: sessions, exercises from the library, reps, sets, core finishers, warm-up and number of weeks.
- **Train:** a week picker, sessions with progress bars, and per-set kg and reps. Each exercise shows last week's best, and ticking a set starts a rest timer.
- **Exercise library:** 64 exercises, each with an animated figure, the muscles worked, equipment, steps, a form tip and an easier alternative.
- **Learn:** Start here, How heavy should I lift?, Staying safe, and a Nutrition guide with a calorie, protein and water calculator.
- **Progress:** heaviest set per exercise, week by week, plus totals.
- **Backup:** copy and restore your data as text.

## Files

| File | What it is |
| --- | --- |
| `app.html` | The app: markup, styles and logic. Edit this. |
| `index.html` | Generated by `./build.sh` from `app.html`. This is what gets hosted. |
| `exercises.js` | Exercise library (`LIB`), animations (`FIG`) and the figure engine. |
| `guides.js` | Beginner and nutrition guides (`GUIDES`) and ready-made plans (`TEMPLATES`). |
| `config.js` | Supabase URL and publishable key. Leave empty for on-device mode. |
| `supabase/schema.sql` | Database table and row-level security. |
| `SETUP.md` | How to set up accounts and put it online. |
